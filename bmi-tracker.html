🍽 OMAD Meal Plan

方案 A · 跑步日 需能量

≈ 800-900 kcal
  • 酱牛肉 100g（30g蛋白）
  • 去皮鸡腿 1只（25g蛋白）
  • 煮红薯 1个（中）— 慢碳
  • 黄瓜 1根 + 生菜不限
  • 香菇酱少许调味
  • 生抽+醋+蒜

方案 B · 力量日 轻食

≈ 650-750 kcal
  • 煮鸡蛋 3个（21g蛋白）
  • 火龙果 1个 — 纤维+甜味
  • 黄瓜 1根 + 胡萝卜 1根
  • 生菜不限 + 油醋汁
  • 青汁粉 1杯（饱腹）

方案 C · 周六换口味

≈ 750-850 kcal
  • 酱牛肉 + 煮鸡蛋 2个
  • 火龙果半个
  • 黄瓜生菜沙拉
  • 或：鸡腿肉撕碎拌香菇酱
  • 牛乳冰淇淋 1份（奖励）

牛乳冰淇淋奖励 / 放纵每周最多 1 次 · 放在周六 OMAD 餐内

💡 Key Reminders

  • 进食窗口：跑步日 15:00-23:00 / 非跑步日 12:00-20:00
  • 跑后不进食：只喝冷茉莉茶/淡盐水/盐汽水/黑咖啡
  • 花生米是隐形陷阱：100g=550 kcal，一顿 OMAD 的热量
  • 红薯是好碳水：跑前 3h 吃，给肌肉充糖原
  • 饮水 ≥ 2L/天，尤其跑后补充 500ml+
  • 黑咖啡可空腹喝：提升运动表现 + 抑制食欲
  • 青汁粉：饥饿感时冲 1 杯，填充胃部
